## 🔐 About Me

I'm an Application Security professional with 8 years of experience securing applications, cloud-native environments and modern software architectures.

I focus on embedding security throughout the Software Development Lifecycle (SSDLC), helping engineering teams identify risks early, make informed security decisions and build secure, resilient products.

My interests and experience span Application Security, Product Security, Security Architecture, Threat Modelling, Cloud Security, Infrastructure as Code (IaC) Security, DevSecOps and AI-enabled security automation.

## 🛡️ Areas of Expertise

- **Application & Product Security:** Secure SDLC, OWASP Top 10, API Security, Security Assessments and Secure Code Reviews.
- **Security Architecture:** Threat Modelling, Secure Design Reviews, Risk Assessment and Security Requirements.
- **Cloud & IaC Security:** AWS Security, Infrastructure Security, Cloud Misconfiguration Assessment and Container Hardening.
- **DevSecOps:** SAST, DAST, SCA, IAC Security, Secrets Management, CI/CD Security and Security Automation.
- **Vulnerability Management:** Risk-based Prioritisation, Remediation Strategy and Security Posture Management.
- **AI Security & Automation:** RAG-based Security Assistants, Developer Enablement and Workflow Automation.
